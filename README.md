# 华星园社区 - 智能考勤管理系统 (Android 原生 APK 工程)

本项目是专为**华星园社区**量身定制的轻量级、班组代记模式智能考勤与假勤管理移动端 App。
设计采用了极具未来感的 **AI 概念暗黑毛玻璃风格（Dark Obsidian Glassmorphism）**，配备了高对比度多维假勤指示光环与现代微交互。

---

## 📱 核心业务功能与规则实现

1. **员工档案与信息管理**
   - 支持员工编号、姓名、手机号管理。
   - 支持**本地相册选择**与**手机摄像头实时拍照**上传员工头像（原生 WebView 权限与 WebChromeClient 深度打通）。
2. **假勤额度初始化设置**
   - 支持每个员工每年**年假**与**病假**额度单独设定，也支持一键**批量设置**。
3. **假勤登记实时余量显示**
   - 登记请假弹窗顶部与请假类型选择按钮上，实时动态显示员工当前可用额度（例如：`余 32h`、`余 80h`、`余 4h`、`不限额`）。
4. **整小时规则计算**
   - 所有的请假与加班均按**整数小时**核算：4 小时折合半天，8 小时折合全天，支持快捷选择与自定义小时输入。
5. **请假类型与扣减闭环**
   - **年假**：按所选小时扣减该员工的年假剩余额度。
   - **病假**：按所选小时扣减该员工的病假剩余额度。
   - **调休**：按所选小时扣减该员工累计的调休额度池。
   - **事假**：常规记录，不扣减额度。
6. **加班/值班类型管理与调休池累计**
   - 加班类型包括：**值班**、**加班**。
   - 登记加班/值班时长后，按 1:1 自动累加至该员工的**调休额度池**中。
7. **全勤免操作与次日自动归档**
   - 默认员工当日即为**全勤在岗 8h**，无需专门打卡。
   - **无须保存按钮**：任何假勤记录录入或删除均实时自动持久化保存（LocalStorage & 本地缓存）。
   - 次日 00:00 自动归档汇总前一日数据并重置当日看板。
8. **每日多条记录同时并存与灵活管理**
   - 每位员工当日可同时存在多条请假或加班记录。
   - 每新增一条记录，直接在卡片操作按钮下方平滑追加一行明细。
   - 支持随时单条撤销删除，并即时回滚对应的扣减或增加额度。

## 🛠️ 获取与编译 APK 安装包指南

本项目已搭建完备的标准 Android 工程结构（包含硬件加速 WebView、文件选择器适配、状态栏暗黑沉浸式适配及国内阿里云 Maven 镜像加速）：

```text
考勤APP/
├── .github/workflows/build-apk.yml  # GitHub Actions 云端一键自动出包脚本
├── app/
│   ├── build.gradle                 # App 构建配置 (minSdk 24, targetSdk 34)
│   └── src/main/
│       ├── AndroidManifest.xml      # 相机/存储/网络权限声明
│       ├── java/.../MainActivity.kt # 原生桥接层 (拍照/相册/物理返回键拦截)
│       └── assets/
│           ├── index.html           # 全功能 AI 视觉考勤交互主界面
│           └── manifest.json        # PWA / WebAPK 独立应用配置
├── build.gradle                     # 根构建配置 (配置阿里云国内加速源)
├── settings.gradle
└── start-preview.js                 # 局域网真机无线免装极速体验服务
```

### 方式一：Android Studio 一键打包（推荐，最快30秒）
如果您本机已安装或计划安装 Android Studio：
1. 打开 **Android Studio**，选择 `File -> Open`。
2. 选中本项目目录：`c:\Users\gaoyu\OneDrive\文档\AI\Antigravity\考勤APP`。
3. 等待项目完成 Gradle 同步（已配置国内阿里云源，无需担心网络超时）。
4. 点击顶部菜单：`Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`。
5. 构建完成后，右下角弹窗点击 `locate`，即可在 `app/build/outputs/apk/debug/` 下拿到 `app-debug.apk` 安装包直接传至手机安装。

---

### 方式二：GitHub Actions 云端 0 配置出包（电脑无需安装任何开发环境）
工程中已预置了自动出包工作流文件 `.github/workflows/build-apk.yml`：
1. 将当前工程上传/推送到您个人的 **GitHub** 仓库。
2. 进入仓库页面的 **Actions** 选项卡，工作流会自动触发执行（基于 Ubuntu 虚拟机自动配置 Java 17 与 Android SDK）。
3. 约 1~2 分钟编译完成后，在当次构建产物（Artifacts）中即可直接下载 `huaxingyuan-attendance-debug-apk.zip`，解压即得 `.apk` 文件。

---

### 方式三：手机局域网极速体验与桌面安装（无需编译直接用）
如果您想立即在手边的手机上体验这款 App：
1. 在项目根目录下打开命令行运行：
   ```bash
   node start-preview.js
   ```
2. 确保手机与电脑连接同一 Wi-Fi，用手机浏览器（如 Chrome、自带浏览器、微信）访问终端打印出的局域网地址：
   ```text
   http://192.168.1.2:3000
   ```
3. 在手机浏览器菜单中点击 **「添加到主屏幕」** 或 **「安装应用」**，即可像原生 APK 应用一样，生成独立的桌面图标启动并支持离线使用。
